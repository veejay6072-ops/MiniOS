# MiniOS

A Java desktop-style learning app for operating system concepts.

## Includes

- CPU Scheduling
- Banker's Algorithm
- Paging
- Page Replacement
- Segmentation
- Fragmentation
- Disk Scheduling
- Multiprogramming

## Requirements

- Java JDK 17 or later

## Run

Open the project in VS Code, then run:

    Main.javas

You can also run [Main.java](opersys/Main.java) from VS Code.
